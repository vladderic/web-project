# Project Spotlight

A single-page car discussion forum for car enthusiasts to share, browse, and discuss their builds — built with vanilla HTML, CSS, and JavaScript.

## Features

- **Browse builds** — A gallery of car build showcases with images, build stories, and owners.
- **Filter by category** — Sort builds into Muscle, JDM, Trucks, and Euro.
- **Like builds** — React to a build with a 👍 like button.
- **Comment** — Discuss builds directly under each spotlight.
- **Submit your build** — Share your own project via the submission form.

## How this project works

This project is built in phases using OpenCode as an AI assistant.

- `project_brief.md` — The planning document covering concept, visual plan, interactions, and architecture.
- `index.html` — The HTML structure of the website.
- `styles.css` — The visual design: colors, layout, typography.
- `script.js` — The interactive behavior: events and functions.

Build order: plan first, then HTML, then CSS, then JavaScript — one layer at a time.

## Tech stack

Vanilla HTML, CSS, and JavaScript — no libraries or frameworks.
